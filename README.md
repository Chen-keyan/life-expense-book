# 生活费账本 · life-expense-book

给大学生用的记账网页。打开就回答一个问题：**这个月还能花多少钱，钱都花在哪了。**

不是又一个待办清单式的记账工具。首页最上面就是一块半圆仪表盘，直接告诉你"还能花 ¥1,346"；下面一句话会告诉你"照前 3 天的花法，月底要花 ¥1,539，超预算 ¥39"——**它不只报账，还提醒你照这样下去会怎样**。

---

## 跑起来

```bash
pip install -r requirements.txt
python app.py
```

然后打开 <http://127.0.0.1:5001>

第一次打开是空账本，点页面底部的 **「造点示例数据」**，会生成两个月、约 95 条像真的学生流水，所有图表立刻就有东西看。

## 功能

| | |
|---|---|
| 首屏仪表盘 | 本月还能花多少，弧线就是预算用掉的比例，超支时整条变红 |
| 月底预测 | 按"已经过去几天的日均"推算月底总花销，超支会提前警告 |
| 钱去哪了 | 环形图 + 分类排行，看出奶茶到底喝掉了多少钱 |
| 每天花了多少 | 柱状图里有条虚线是"每天额度"，超过它的那天会被点名 |
| 流水 | 按天分组，每天带小计，点任意一行就能改 |
| 翻月 | 左右翻看历史月份，过去的月份会自动切换成"这个月花了多少、结余多少"的口径 |
| 记一笔 / 改一笔 | 弹层共用，10 个支出分类 + 5 个收入分类，支持补记以前的账 |
| 月预算 | 底部可改，改完所有数字立刻重算 |

## 技术栈

零构建工具，全部是看得懂的东西：

- **前端**：原生 HTML + CSS + JavaScript（没有框架、没有 npm、没有打包）
- **后端**：Python + Flask（一个 `app.py` 就跑起来）
- **数据库**：SQLite（Python 自带，就是项目里的一个 `data.db` 文件）

## 接口一览

| 方法 | 路径 | 作用 |
|---|---|---|
| GET | `/api/records?month=2026-11` | 查某个月的账单 |
| POST | `/api/records` | 记一笔 |
| PUT | `/api/records/<id>` | 改一笔 |
| DELETE | `/api/records/<id>` | 删一笔 |
| DELETE | `/api/records/all` | 清空 |
| POST | `/api/budget` | 改月预算 |
| GET | `/api/stats?month=2026-11` | 要统计（收入/支出/结余/分类占比/每日支出/预测） |
| POST | `/api/demo` | 生成示例数据 |

有个设计原则：**所有数字都在后端算好再发给前端**，前端一个数字都不自己算。所以 `/api/stats` 返回的是"厨房做好的菜"，不是原材料。

## 两个 URL 小技巧

- `/#add` —— 打开就直接弹出"记一笔"，可以存成书签
- `/?month=2026-10` —— 直接看某个月

## 关于数据

`data.db` 里是你的真实消费记录，已经在 `.gitignore` 里排除了，不会传上 GitHub。换台电脑跑起来是空的，点一下"造点示例数据"就行。
